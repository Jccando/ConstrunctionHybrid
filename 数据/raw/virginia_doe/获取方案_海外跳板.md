# Virginia DOE 学校造价数据获取方案（海外跳板）

> 实测结论：中国 IP 直连 `doe.virginia.gov`（Akamai 403）、`data.ca.gov`（Cloudflare 1009）、`web.archive.org`/`zenodo.org`（HTTP 000，GFW）**全部不可达**。GitHub/Kaggle 也无任何 VA 项目级造价镜像。
> Virginia DOE 是**唯一含 项目级总造价 + 面积 + 单方造价**的数据（金标准），值得花 1 天搭海外跳板获取。

## 推荐方案：GitHub Actions 美区 runner 一键抓取（免费、最稳）

原理：GitHub Actions 的 `ubuntu-latest` runner 在美国，可达 archive.org 与 VDOE 官网；抓到后 commit 回**私有仓库**，中国端 `git pull`（github.com 中国通常可达，必要时走 ghproxy）。

### 步骤
1. 在 GitHub 建一个**私有**仓库（如 `vdoe-data`），本地 `git init` 并 push。
2. 在仓库根建 `.github/workflows/fetch-vdoe.yml`（内容见下）。
3. GitHub 网页 → Actions → `Fetch VDOE` → Run workflow。
4. 中国端：`git pull` 即得 `vdoe_school_construction_cost.xlsx`。

### `.github/workflows/fetch-vdoe.yml`
```yaml
name: Fetch VDOE School Construction Cost
on:
  workflow_dispatch: {}
  schedule:
    - cron: "7 3 1 * *"   # 每月1日自动跑（避开整点）
jobs:
  fetch:
    runs-on: ubuntu-latest   # 美国 IP
    steps:
      - uses: actions/checkout@v4
      - name: Query Wayback CDX for VDOE snapshots
        run: |
          curl -s "https://web.archive.org/cdx/search/cdx?url=doe.virginia.gov/*school-construction*&output=json&fl=original,timestamp,statuscode,mimetype&collapse=digest" > cdx.json
          curl -s "https://web.archive.org/cdx/search/cdx?url=doe.virginia.gov/*facilities*&output=json&fl=original,timestamp,statuscode,mimetype&collapse=digest" >> cdx.json
      - name: Find & download latest Excel/PDF snapshot
        run: |
          python3 - <<'PY'
          import json, urllib.request, sys
          rows=[]
          for line in open('cdx.json'):
              try: rows+=json.loads(line)
              except: pass
          # rows[0] is header
          cands=[r for r in rows[1:] if len(r)>=4 and r[2]=='200' and ('excel' in (r[3] or '').lower() or 'spreadsheet' in (r[3] or '').lower() or r[0].lower().endswith(('.xlsx','.xls')))]
          cands.sort(key=lambda r:r[1], reverse=True)
          if not cands:
              print('No Excel snapshot found; downloading PDF fallback'); sys.exit(0)
          orig,ts=cands[0][0], cands[0][1]
          url=f"https://web.archive.org/web/{ts}/{orig}"
          print('SNAPSHOT_URL='+url)
          urllib.request.urlretrieve(url, 'vdoe_school_construction_cost.xlsx')
          PY
      - name: Commit
        run: |
          git config user.email "bot@local" && git config user.name "bot"
          git add -A && git commit -m "auto: VDOE snapshot $(date -u +%F)" || exit 0
          git push
```
> 中国端拉取（若 github 慢）：`git clone https://ghproxy.com/https://github.com/<you>/vdoe-data.git`

## 备选方案
- **VPN 手动**：开美国节点 → 浏览器访问 `https://www.doe.virginia.gov/data-reports/reports/school-facilities` → 下载年度 School Construction Projects Excel 附录。
- **美区云 VM**：AWS `t3.micro` 免费套餐（us-east-1）一键 curl VDOE + 上传到自己的 S3/OneDrive，再国内下载。
- **找人代下**：海外合作者/学生下载后传回。

## 拿到后要核验的字段（金标准应含）
School Division / Project Type(New/Addition/Renovation) / Grade Span / **Square Footage** / **Total Construction Cost** / **Cost per Square Foot** / Funding Source / Year。

## 备注
- 若 Virginia 始终拿不到，**NYC SCA（已下载）+ ComStock 补面积**可作退路（见 `../数据下载清单.md`），但单方造价/成本驱动分析(E4)会偏弱。
- CA OPSC 已弃用（仅拨款额+无面积+被墙）。
