# 公共建筑混合学习造价研究：100% 公开数据可行性方案（详细报告）

> 约束：研究者无法自采数据。本方案完全基于可公开下载、授权清晰的数据集。
> 检索覆盖 40 个候选数据集（UCI/Zenodo/Mendeley/Kaggle/USAspending/World Bank/CA OPSC/Virginia DOE/中国造价信息网等）。

## 一、残酷现实判定

### 核心结论：部分成立（有重大前提），不是简单的"否"

**对【中国公共建筑】：不存在可公开下载的项目级造价数据。** 这是无法绕开的可行性障碍：
- 公共资源交易平台（cebpubservice、深圳 szggzy、苏州 ggzy 等）的招标控制价/中标价以**单项目 PDF 附件**发布，无批量 API、无 CSV/Excel、无机器可读接口；汇总表缺面积/层数/结构类型等 ML 特征；平台 ToS 限制抓取，**不可复现**。
- ccea.pro 是付费数据资产平台；MOHURD 只发行业总量统计；DB42/T 2176-2024 只是数据**格式**标准、不发布数据。
- 信息价/造价指数（gczj.com.cn、zaojiaku 等）经直接核实只是材料单价表和宏观指数，**零项目行**。
- Lyu et al. (ACM AIDMM'26) 的 **520 条广东公共项目数据未公开**（中国建筑 ML 论文常态）。

**对【美国/国际公共建筑】：存在真实、可下载、授权清晰的项目级造价数据。**

| 数据集 | 真实性 | 项目级 | 含物理特征 | 授权 | 公共建筑 |
|---|---|---|---|---|---|
| California OPSC 学校设施项目 | 真实拨款额+地方配套 | 是（每校一行） | **有平方英尺** | CA 公有领域 | 是（K-12 学校） |
| Virginia DOE 学校造价年度表 | 真实上报造价 | 是（每校一行） | 类型/层级，面积部分可得 | VA 公有领域 | 是（K-12 学校） |
| USAspending.gov NAICS 2362 | 真实合同授予 $ | 合同交易级，需聚合到父奖励 | 几乎无，需外挂拼接 | 美国公有领域 | 是（联邦法院/医院/办公楼） |
| World Bank 合同授予（Works+教育/卫生/公共行政） | 真实合同 $ | 合同级，可聚合到 Project ID | 仅行业标签 | **CC BY 4.0** | 是（发展中国家学校/医院/办公楼） |
| GSA Library of Buildings | 真实建筑特征 | 是（每楼一行） | 面积/类型/年代/结构 | 美国公有领域 | 是（联邦公共建筑）——但**无造价**，仅作特征拼接源 |

**对【住宅（方法论锚点）】**：UCI #437（372 条德黑兰住宅，CC BY 4.0）是唯一干净的项目级真实造价锚点。

**一句话判定**：你不缺"真实公共建筑造价数据"（美国学校+联邦建筑+世界银行能凑出**几千到上万条**）；你缺的是"**中国**公共建筑项目级造价数据"，而这无法自采、也无法公开获取。因此论文定位应为"**真实数据验证方法论 + 衍生标签扩展规模 + 中国单价做语境迁移**"。

## 二、推荐管线：双臂设计

```
┌──────────── Real-Anchor Arm（验证与定标，全部真实造价）────────────┐
│ UCI #437 (372 住宅, CC BY)      → 方法论有效性证明               │
│ CA OPSC + Virginia DOE (真实学校)→ 公共建筑真实 held-out 验证集  │
│ USAspending NAICS2362 (+GSA拼)  → 联邦公共建筑真实标签（清洗后）│
│ WB 合同授予(教育/卫生/公共行政)  → 国际公共建筑真实标签          │
└──────────────────────────────────────────────────────────────────┘
                       ↓ 定标/校准衍生引擎
┌──────── Derived-Scale Arm（规模与公共建筑覆盖，衍生标签）────────┐
│ 特征源：ComStock(~35万+) / CBECS(~6,700) / DOE Reference(16 原型)│
│   → 面积/类型/年代/气候/HVAC/围护（含学校/医院/办公/图书馆）     │
│ BOM 骨架：Kumar 2024 MT/SS/RC 原型 BOM（须现场确认授权）         │
│ 计价引擎：DDC CWICR (55,719 工程项, 上海/CNY + 向量库, CC BY)    │
│   → 衍生造价 = Σ(工程量_k × 单价_k) × 地区指数 × 年份指数        │
│ 年份/地区调整：FRED TLPBLCONS / 中国造价指数 / Eurostat CCI      │
└──────────────────────────────────────────────────────────────────┘
                       ↓ RAG+ML 知识增强
┌──────────────────── RAG+ML 臂（知识增强）────────────────────────┐
│ DDC CWICR 的 Qdrant 向量库 → 按建筑 BoQ 语义检索相关单价         │
│ award_description / 政策文本 NLP → 融合进混合模型                │
└──────────────────────────────────────────────────────────────────┘
```

### 衍生项目级造价标签的具体算式

输入特征（来自 ComStock/CBECS）：`floor_area`、`building_type`(PrimarySchool/Hospital/SmallOffice)、`vintage`、`climate_zone`、`hvac_type`、`envelope_uvalue`、`window_wall_ratio`。

1. **生成 BoQ**：建筑类型→工程项束映射（PrimarySchool → {土方、基础、主体结构、屋面、门窗、装修、给排水、暖通、电气}）；工程量 `q_ik` 由面积/类型/结构按原型单方指标推算（混凝土量 ≈ floor_area × 单方混凝土指标，查 Kumar BOM 或 DOE 原型）。
2. **取单价**：DDC CWICR 上海/CNY 变体，对每个工程项 k 取定额单价 `unit_price_ik`；可用 BoQ 描述在 Qdrant 语义检索最相似单价（RAG 接入点）。
3. **衍生造价**：
   ```
   衍生总造价  C_i = Σ_k (q_ik × unit_price_ik) × 地区指数_i × 年份指数_i
   衍生单方造价 u_i = C_i / floor_area_i        （元/m²）
   ```
   - 地区指数：中国样本用信息价/上海定额地区差异系数；美国样本用 GSA 公开指数或 DDC 多区域单价（**RSMeans 不可再分发，禁用**）。
   - 年份指数：FRED TLPBLCONS 或中国造价指数平减到基年（如 2024）。
4. **用真实标签校准**：在 UCI #437 上跑同一套"特征×单价"衍生逻辑，对比衍生值 vs 真实造价，报告 MAPE/R² 作为衍生引擎系统误差刻度；在 CA OPSC/Virginia 真实学校造价上再做公共建筑层面交叉校准（跨币种用 PPP/汇率 + 指数转换）。校准后的衍生标签才进大规模训练。

### 样本量现实

| 来源 | 性质 | 估计行数 |
|---|---|---|
| CA OPSC 学校项目 | 真实，项目级，公共建筑 | ~2,000–5,000（清洗后） |
| Virginia DOE 学校造价 | 真实，项目级，公共建筑 | ~200–400 |
| USAspending NAICS 2362（聚合到楼） | 真实合同$，公共建筑 | ~500–3,000（须清 M&O + 特征拼接） |
| World Bank 建筑行业合同 | 真实，合同级，公共建筑 | ~3,000–10,000 |
| UCI #437 | 真实，住宅（方法锚点） | 372（独立验证臂） |
| **真实公共建筑造价合计** | | **~5,000–15,000（保守清洗到 ~3,000–5,000 干净行）** |
| ComStock × DDC 衍生 | 衍生标签，公共建筑 | 数万至数十万（按需采样） |

对 stacking/GA-ANN/PSO-SVR/LightGBM 集成方法，3,000–8,000 真实行已足够；CNN 等深度模型偏紧，需衍生扩展或退回浅层集成。

## 三、论文 framing 策略

### 能站住脚的贡献（DO 强调）
1. **方法论有效性**：在多个真实造价数据集（UCI 住宅 + CA/Virginia 学校 + USAspending 联邦 + WB 国际）上系统对比 stacking/GA-ANN/PSO-SVR/CNN+tree/RAG+ML，给可复现横向基准。
2. **可解释性**：SHAP 做**设计阶段成本驱动分析**（面积、层数、结构类型、HVAC、气候区对造价的影响）——设计阶段造价管理核心卖点。
3. **跨方法对比与最优混合策略**：哪种集成/混合架构在哪种数据规模（真实小样本 vs 衍生大样本）下最优。
4. **可复现的 100% 公开基准**：公共建筑造价数据稀缺背景下，提供任何人可重跑的管线本身就是贡献。
5. **中国语境的单价迁移**：DDC 上海 CNY 定额 + 信息价指数，演示框架如何迁移到中国（即便无中国真实标签）。
6. **衍生标签引擎的校准方法论**：用少量真实标签定标大规模衍生集并量化衍生误差——方法学贡献。

### 要弱化的表述（WEAKEN）
1. **绝对精度**：真实数据特征薄、衍生标签非市场实际造价——不宣称"高精度造价预测"，改用"误差可控的设计阶段造价估计区间"。
2. **中国实际工程验证**：不写"验证于中国公共建筑项目"；改"框架在中国单价语境下的可迁移性演示"。
3. **衍生标签代表性**：全程明示"unit-price-derived design-stage cost estimates"，限制章节写清与实际造价差异。
4. **深度模型在小样本上**：真实小样本别硬上 CNN 顶端，至少给"真实子集 vs 衍生全集"学习曲线。

### 预防性回应审稿人三大必问
- **"为什么没有中国数据？"** → 中国项目级造价数据公开渠道经核实不可下载（交易中心 PDF、ccea 付费、Lyu 数据未公开），故采用"真实多国数据验证 + 中国单价迁移"的诚实路径，引 DB42/T 2176-2024 示知标准已存但数据未公开。
- **"你的标签是衍生的、不是真实造价。"** → 衍生标签仅用于规模扩展，用 UCI/OPSC 真实标签校准并报告 MAPE；核心精度结论锚定真实 held-out 集。
- **"USAspending 合同粒度不对、特征缺失。"** → 公开清洗协议（聚合到父奖励、PSC Y-码 + NAICS 2362 双过滤、剔 M&O），与 GSA Library of Buildings 拼接补物理特征，保留字段与丢弃率透明披露。

## 四、三套可选方案

### 方案 A：保守档（**强烈推荐**，审稿风险低）
- **数据集**：UCI #437 + CA OPSC + Virginia DOE（全部真实、项目级、授权清晰）。
- **样本量**：~2,500–6,000 真实行（372 住宅验证 + 2,000+ 真实公共学校）。
- **方法**：stacking / LightGBM / GA-ANN / PSO-SVR 为主，CNN+tree 作对比。
- **卖点**：Real-data validated hybrid learning for public school construction cost estimation——真实学校造价、设计阶段成本驱动、可解释、可复现。
- **审稿风险：低**。审稿人无法攻击数据真实性；软肋是"仅学校 + 仅美国"，定位清晰即可。
- **适合**：CAS 四区 / JCR Q3 OA，方法论稳健型。

### 方案 B：中等档（平衡，审稿风险中）
- **数据集**：方案 A + USAspending NAICS 2362（聚合 + GSA 拼接）+ World Bank + ComStock×DDC 衍生扩展。
- **样本量**：5,000–15,000 真实 + 数万衍生。
- **方法**：全套混合（含 DDC 向量库 RAG+ML）。
- **卖点**：多源真实 + 衍生扩展的混合学习公共建筑造价框架，跨国、含中国 CNY 单价。
- **审稿风险：中**。需仔细 framing 衍生标签与 USAspending 清洗；数据工程量 2–3 个月。
- **适合**：目标 Q3 偏上、有时间做数据工程。

### 方案 C：进取档（仅当能验证 Korea 且时间充足，审稿风险高）
- **数据集**：方案 B + Korea data.go.kr/G2B 공사비（**须先现场验证**）+ 全量 ComStock 百万级衍生 + USAspending award_description NLP。
- **样本量**：15,000+ 真实 + 十万级衍生。
- **审稿风险：高**。Korea 数据未验证、衍生占比高、多源对齐脆弱。

## 最终建议

采用**方案 A** 稳妥起步，必要时升级到 **方案 B**。先在 UCI #437 上把混合学习管线跑通并报告真实精度，再用 CA OPSC + Virginia DOE 迁移到真实公共学校建筑，最后（若需规模与中国语境）接入 ComStock×DDC 衍生扩展。全程诚实标注真实 vs 衍生标签，卖点压在**方法论有效性、可解释性、设计阶段成本驱动分析、可复现公开基准**，弱化绝对精度与中国实地验证。这样一篇论文在 CAS 四区 / JCR Q3 OA 是站得住脚的。
