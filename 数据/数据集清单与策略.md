- **中国公共建筑项目级造价数据：不可公开下载。**（交易中心 PDF、ccea 付费、信息价零项目行、ACM2025 广东 520 项未公开）
- **美国/国际公共建筑：有真实可下载的项目级造价数据** → 不必 100% 衍生标签。
- **UCI #437（372 真实住宅）**：方法论锚点。
- **论文定位**：真实多国数据验证方法论 + 衍生标签扩展规模 + 中国单价做语境迁移（**非**"中国公共建筑真实造价预测"）。

## 双臂管线

```
真实锚定臂（验证/定标）          衍生扩展臂（规模/公共建筑覆盖）
UCI#437 → 方法有效性             特征源: ComStock/CBECS/DOE
CA OPSC + Virginia → 公共学校 ──校准──▶ 衍生造价 = Σ(q×单价)×地区指数×年份指数
USAspending(+GSA) → 联邦建筑           计价引擎: DDC CWICR 上海/CNY
World Bank → 国际公共建筑              BOM骨架: Kumar 2024
                                   RAG+ML: DDC Qdrant 向量库语义检索单价
```

## 衍生造价算式

```
衍生总造价  C_i = Σ_k (q_ik × unit_price_ik) × 地区指数_i × 年份指数_i
衍生单方造价 u_i = C_i / floor_area_i        （元/m²）
```
- q_ik：工程量，由面积/类型/结构按原型单方指标推算
- unit_price_ik：DDC CWICR 上海/CNY 定额单价（可 RAG 检索）
- 校准：先在 UCI#437 真实造价上跑同一逻辑，报告 MAPE 作系统误差刻度；再在 CA OPSC 真实学校造价上交叉校准

## 重点关注：OpenConstructionEstimate (DDC CWICR)

**它是什么**：开放的**工项/单价/资源定额库（rate library）**，**不是项目级数据集**。每条是一个工序单价（含人工/材料/机械分解与区域单价）；55,719 工项 + 27,672 资源，85 字段。

**关键事实**：`.parquet`(~55MB，官方推荐用于 ML) / `.xlsx` / `.csv` / Qdrant 快照；**11 区域含 ZH Shanghai/CNY**（`ddc_zh_shanghai`）；**CC BY 4.0**（须署名 Boiko, A. 2025）；方法论=资源法计价(技术定额×区域单价)；免费 REST API `buildcalculator.io/api/v1/search`（60 次/分）；预计算 OpenAI 向量(3072维)+Qdrant。

**对本论文 4 个用法**：① 衍生造价标签的单价引擎（最核心）；② RAG 增强的混合学习模型（潜在方法创新点）；③ 富特征源；④ 跨区域造价对标。

**边界**：非项目级（不能替代 UCI/真实学校造价）；仅 Shanghai/CNY 非全国代表；定额源自欧亚/东欧标准化需论证在华适用性。**币种已核验(2026-07)**：GitHub `Asia-China-Dinge` 目录 Catalog CSV 全为 **CNY**（2,681 条工料机单价）；注意 `buildcalculator.io` 免费 API 返回的是 **EUR** 统一库（两者不同，用 API 需汇率换算）。完整 55,719 工项 parquet（含向量）需 `git lfs clone`。
